# CSC584 Individual Assignment 1
## Personal Profile Web Application

### Project Description
This project is a Personal Profile Web Application developed for CSC584 Individual Assignment 1.

The application allows users to enter their personal information through an HTML form. The submitted information is processed using Java Servlet and displayed on a JSP page.

### Technologies Used
- HTML
- CSS
- Java
- Java Servlet
- JavaServer Pages (JSP)
- NetBeans IDE 8.2
- GlassFish Server 4.1.1

### Application Features
1. Full Name
2. Student ID
3. Programme
4. Email Address
5. Hobbies
6. Short Self-Introduction

### System Process
HTML Form → Java Servlet (HTTP POST) → JSP Profile Display

### How to Run the Application
1. Open NetBeans IDE 8.2.
2. Open the PersonalProfile project.
3. Configure GlassFish Server 4.1.1.
4. Right-click the project and select Run.
5. Fill in the personal profile form.
6. Click Submit Profile.
7. View the submitted information on the profile page.
